# CampusConnect

A DevOps-driven campus networking and collaboration platform where students can create profiles, share blogs and project ideas, showcase achievements, and connect with peers and faculty.

## Problem Statement
Students currently rely on scattered platforms (WhatsApp groups, email, word-of-mouth) to find teammates, share work, or discover internships and mentors. CampusConnect brings this into one campus-specific platform.

## Tech Stack
- Backend: Flask (Python)
- Database: SQLite
- Frontend: HTML, CSS, JavaScript
- CI/CD: GitHub Actions
- Deployment: Render (planned)

## Setup Steps
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the app: `python app.py`
4. Open `http://127.0.0.1:5000` in your browser

## Git Workflow
- `main` branch is always stable
- New features are built on `feature/<name>` branches
- Changes are merged via reviewed Pull Requests
- GitHub Actions runs tests automatically on every push
